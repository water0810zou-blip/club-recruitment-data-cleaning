# 招新报名数据清洗与统计 v0.1.0

协会招新报名表（问卷导出的 CSV）的**体检 → 校验 → 清洗 → 统计**小工具。
零第三方依赖，只要 Python 3.8+；全程只读原始文件，结果另存，绝不覆盖报名表。

一条命令跑完：`python run_all.py`

---

## 当前功能

### 1. 读入与概览（需求1）

- 总行数 / 列数 / 跳过的空行数 / 必填缺失行数
- **每列空值数与空值率**（自动区分必填项与选填项）
- **完全重复的行**（所有字段逐字相同）分组列出行号
- 表头自动归一（认 `1. 姓名`、`第一志愿`、`email` 各种写法）、编码自动识别（utf-8-sig / utf-8 / gb18030）

### 2. 校验与清洗（需求2）

把每一条有问题的记录单独拎出来，并写清**为什么有问题**：

| 级别 | 问题类型 | 判定 | 处理 |
| --- | --- | --- | --- |
| 错误 | 必填项为空 | 姓名/学号/邮箱/志愿1 为空 | 剔除 |
| 错误 | 学号格式 | 非半角纯数字（字母、连字符、空格、全角数字、Excel 带出的 `.0`） | 剔除 |
| 错误 | 邮箱格式 | 缺 `@`、多个 `@`、含空格、非 ASCII | 剔除 |
| 错误 | 邮箱与学号不匹配 | 域名不是 `smbu.edu.cn`，或前缀不等于学号（含 `@stu.` 子域名） | 剔除 |
| 错误 | 重复报名 | 同一学号出现 ≥2 次 | 剔除多余提交（保留第 1 次） |
| 提示 | 两个志愿填成同一个 | 志愿1 == 志愿2 | 保留并标注 |
| 提示 | 志愿不在部门清单内 | 志愿不在 `--choices` 清单里 | 保留并标注 |
| 提示 | 姓名疑似异常 | 姓名里混入数字或英文字母 | 保留并标注 |

- 输出 `问题清单.csv`（一行一条记录）与 `问题清单_明细.csv`（一条原因一行，便于按人回信）
- **原文件保护**：跑完前后各算一次 sha256 并打印校验结果
- 错误级 = 必须联系同学更正；提示级 = 可疑、留人工确认，仍然算干净数据 —— 避免机器一刀切误杀

### 3. 统计与导出（需求3）

- 数据前后对比：原始 → 剔除 → 参与统计
- **按第一志愿分组统计**（人数/占比/条形图）
- **按中心汇总**（7 个部门归并到 技术研发中心 / 运营管理中心 / 对外合作中心）
- **两个志愿的填写情况**：两志愿都填 / 只填一个 的人数与占比
- 导出清洗后干净数据 CSV（首列 `原始行号` 可回查问卷）、被剔除的行及原因、各汇总表 CSV 与 Markdown 版

## 快速开始

```bash
git clone <本仓库地址> && cd 招新报名数据清洗与统计
python run_all.py                                   # 用仓库自带示例数据跑一遍

python run_all.py -i "D:/downloads/2026招新报名表.csv" --output-dir "结果/"   # 换成你自己的表
python run_all.py -i 报名表.csv --id-length 10       # 顺带校验学号位数
python run_all.py -i 报名表.csv --choices "项目开发部,品牌传播部,赛事运营部"   # 换成你们协会的部门
```

全部参数见 `python run_all.py --help`。

## 质量

- **53 条单元测试**全绿：`python -m unittest discover -s tests`
- 覆盖每条校验规则的边界（全角数字、大小写域名、空学号不重复判重……）、
  产物自洽性（各组人数之和 = 合计 = 干净数据行数）、**输入文件不被修改**、跑两次产物逐字节一致
- 数据是**合成假数据**：`data/signup_raw.csv` 由固定种子（SEED=20260930）生成，
  不含任何真实同学信息，可放心改用来调试

## 已知边界

- 部门/中心清单内置的是示例用的 7 个部门，换协会实际清单请用 `--choices` 传入
- 默认不校验学号位数（拿不准 8 位还是 10 位，硬校验会误杀几百行）
- 第一志愿不在「部门 → 中心」映射里的人不会静默并入任何中心，
  汇总表单独列 `(志愿不在中心清单内)` 一行，等人工确认归属
- 统计默认基于清洗后的数据；要看原始口径对比加 `--keep-problems`
