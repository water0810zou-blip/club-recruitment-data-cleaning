## 关键实现说明

1. **纯数字判定不用 `str.isdigit()`**：Python 里 `"２０２３".isdigit()` 是 `True`，
   而问卷导出里的**全角数字**是最常见的坑之一。改用只认半角 `0-9` 的正则，
   并在说明里写清「其中包含全角数字，请改回半角」。
2. **邮箱三层判定**：格式合法 → 域名 → 前缀，说明区分
   「域名写错了」「多了 `stu.` 子域名」「前缀与学号不一致」，
   拿到清单就能直接回信给同学，不用自己再猜。
3. **学号非法时不重复扣分**：学号本身不合法（或为空）时，邮箱不再跟它比对，
   避免一行刷出两条同因错误、给人工复核添乱。
4. **规则分两级**：
   - **错误**（剔除）：必填项为空、学号非纯数字、邮箱格式非法、邮箱与学号不匹配、重复报名
   - **提示**（保留）：两个志愿填成同一个、志愿不在部门清单内、姓名混入数字字母、
     学号位数与假设不符（需 `--id-length` 开启）

   需求原文只有「有问题」一个概念。一刀切会误杀（同学可能真的只想去同一个部门的两个组），
   所以把「必须联系同学更正」的判为错误、把「可疑待确认」的判为提示，
   提示级仍然算干净数据，只在清单里被点名。
5. **重复报名保留第 1 次提交**：人只来一次，第 1 次提交通常最早、最完整。
   `--drop-all-duplicates` 可改成全部剔除。学号为空的重复不判重复（空值已在必填项里报过）。
6. **原文件保护的证据**：跑完前后各算一次 sha256 并打印「前后一致」，
   而不是只在 README 里口头承诺。
7. 导出两份清单：
   - `output/问题清单.csv`：一行一条问题记录（问题级别、问题数、逐条原因 + 原始字段）
   - `output/问题清单_明细.csv`：一条问题一行，便于按类型筛选
8. `--fail-on-error`：存在错误级问题时退出码 1，方便放进 CI 或批处理。

## 已知取舍

- 「两个志愿填成同一个」判为**提示**而不是错误，因为需求没规定两个志愿不能相同。
- `@@smbu.edu.cn` 这类算「格式非法」而不是「与学号不匹配」——两者都在问题清单里，
  只是分类不同，不影响人工处理。
