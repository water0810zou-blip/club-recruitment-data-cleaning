## 关键实现说明

1. **字段定义只有一份**：`COLUMNS` + `REQUIRED_COLUMNS` / `OPTIONAL_COLUMNS`。
   三个需求的脚本都从这里取口径，避免「同一件事三个地方各写一遍、口径还不一致」。
2. **表头自动归一**：问卷平台导出常见 `1. 姓名`、`第一志愿`、`Email` 这类写法，
   `_canonical_header` 会去掉题号、折叠空格、按别名表归一，认不出的列原样保留并在概览里提示。
3. **只读保证**：`read_csv_rows` 只以 `r` 模式打开输入文件；所有写出都用
   `write_csv` / `write_text`，并且 utf-8-sig（Excel 双击不乱码）。
4. **空值口径**：`normalize()` 先去掉 BOM、零宽字符、全角空格并折叠连续空格再判空，
   否则「看起来空了其实有个零宽空格」会漏判。
5. **完全重复的行** ≠ 重复报名：这里按「所有字段逐字相同」判，返回重复组与行号；
   按学号判重是需求 2 的事（同学号的其他字段可能不同）。
6. **中文对齐**：按东亚字符宽度计算显示宽度再补空格，否则中文表格在终端里会歪。

## 已知取舍

- 缺少必填列时不猜、不自动改名，直接报错退出（退出码 2），避免静默错算。
- 空值率的分母是数据行数（不含表头），不是文件总行数。
